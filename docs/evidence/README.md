What the pictures show (and what they do not):

* The zip already had a paper-like look. The differences are not a redesign: the suggested-path strip at the top of Self-check, Library and Tools; a Simplify button in the header; cobalt in place of brown for the primary action; a serif heading on Tools and Library on a phone; a darker-but-not-black dark theme with the same card structure.
* The phone view now spends about 160px at the top of Tools on the path strip. That is a cost, accepted so the path is always visible; it is not hidden on small screens.
* The 3D bridge on Home looks the same in both. These are still frames: motion, sound and the Bridge's frame budget are not shown.
* The pane does not always repaint while it is in the background, so each image was taken after a wait; none is a composite or edited.
